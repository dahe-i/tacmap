怎么用

  • 缩放平移：滚轮 / 双指缩放；空白处拖拽平移（任何工具下按住空格或右键也能平移）。
  • 标记：左侧点一个颜色 → 点地图放点 → 在右边输入文字，文字会跟着色点显示在地图上；「选择」可拖动位置、改颜色。
  • 观察：只浏览的档位——拖拽只平移地图，点到点位 / 路线只会选中看信息，挪不动东西。
  • 合并分类：点位筛选条最左边点「合并…」，勾几个分类 →「合并这 N 类」→ 起个名字。合并后筛选栏变短，点一下可整组显隐；分类名右边的 ▸ 展开成员，成员后面的 ✕ 可以单独移出；选中点位后用右侧「归入分类」也能加进去。
  • 路线：连续点击落点，双击或 Enter 结束，Esc 放弃。
  • 改路线：选中路线后，右侧能调线宽、标题字号、标题透明度，给每个拐点起名字；路线标题可以直接拖着换位置。
  • 路线筛选：筛选条左边可以切「点位 / 路线」，路线模式下按条隐藏；「全部」点一下隐藏、再点一下显示。
  • 复制标点：选中一个点按 Ctrl+C，再 Ctrl+V 就在鼠标位置贴一个一样的；右键菜单也能复制 / 粘贴 / 删除。
  • 调透明度 / 纯文字：选中一个点，右侧可以单独调透明度；勾「不显示圆点」只剩文字，勾「点击才显示文字」则平时只留一个点。
  • 点位筛选：顶上那排按钮，官方分类和自己写的文字标注都在里面，点一下就能隐藏 / 显示同一类的点。
  • 删地图：顶部标签上的 × 可以删掉不要的地图；误删了在「方案 → 恢复已删除的地图」里找回。
  • 换底图：点「上传地图」，或者直接把截图 Ctrl+V 粘进来、拖进地图区也行；标注照旧。
  • 保存：标注自动存在本机浏览器；「方案」可以导出 JSON 发给队友。
